PM Desk privacy policy

Last updated: October 6, 2026

1. Who we are

PM Desk is a private, single-owner assistant run by its owner, brokenmelody25@gmail.com. It is not a public service and is not offered to other people. The app manages email sent to one project Gmail account for a property project.

2. Google user data we access

PM Desk connects to one Gmail account, the project mailbox, using two Google permissions:

  • Read-only access (gmail.readonly): reads incoming messages in the project mailbox, including sender, recipients, subject, date, message body, and attachments.
  • Send access (gmail.send): sends email from the project mailbox, only after the owner approves a specific draft.

PM Desk does not access any other Gmail account, Google Drive, contacts, or calendar data.

3. How the data is used

  • Triage: incoming messages are read to decide what needs a reply and what is urgent.
  • Drafting: an AI language model writes a draft reply. The model receives the message text and the app's working instructions. The model's output is stored as a draft.
  • Owner approval: the owner receives each draft, and any notices, in a private Telegram chat with a bot. Nothing is sent to a recipient until the owner approves it in that chat.
  • Sending: approved drafts are sent from the project mailbox. A copy of each sent message is delivered to the owner's own address.
  • Attachments: PDF attachments may have their text extracted, so the model can read them. Extraction runs in a restricted sandbox.

PM Desk does not sell Google user data, does not use it for advertising, does not use it to build profiles, and does not use it to train AI models. Its use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

4. Where the data goes

  • Google: Gmail is the mail service that sends and receives the messages.
  • AI model provider: message text and drafting instructions are sent to the model that writes drafts. This is either a commercial AI API, under that provider's terms, or a language model running on hardware the owner controls. Only the content needed to draft a reply is sent.
  • Telegram: drafts, notices, and the owner's approval commands pass through Telegram's bot service.

No other third party receives the data.

5. Where the data is stored

Mail content, drafts, and logs are stored on a virtual machine on the owner's own computer, in restricted folders that only the app's services can read. Access tokens are stored with restricted file permissions. Encrypted backups may be kept in remote storage, and when they are, they are encrypted before they leave the owner's computer.
